# kiln-cli

The `kiln` command used by the Kiln Claude Code plugin. See the plugin README one level up.

```
kiln search "<query>" [--sources github,hn,...] [--json] [--no-cache]
kiln seeds [--n 6] [--category data_sources]
kiln ledger add|recent|list|show|reject|revive|built|briefed|similar|taste
kiln profile path|init|show
kiln home
```
